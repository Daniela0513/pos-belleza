# Estructura del Sistema POS

## 🧱 Arquitectura

Proyecto frontend organizado por responsabilidades.

---

## 📄 HTML

Cada archivo HTML representa una pantalla del sistema POS.

---

## 🎨 CSS

- styles.css: estilos globales
- login.css: estilos específicos del login

---

## ⚙️ JavaScript

- main.js: funciones generales
- login.js: autenticación
- ventas.js: cálculos de ventas

---

## 🌐 Navegación

Las páginas se conectan entre sí mediante enlaces y JavaScript.

---

## 📈 Escalabilidad

Esta estructura permite agregar backend y base de datos sin reestructurar el proyecto.

login.html y login.css implementan una vista de login con layout en dos columnas,
siguiendo el diseño de Figma del sistema POS Afrodita Belleza.
