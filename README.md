# POS - Tienda de Belleza 💄

Sistema POS (Point of Sale) para una tienda de belleza, desarrollado como aplicación web.

## 📌 Objetivo

Controlar ventas, productos, clientes y reportes diarios de una tienda de belleza.

---

## 📂 Estructura del proyecto

├── index.html # Página principal
├── login.html # Inicio de sesión
│
├── pages/ # Pantallas del sistema
│ ├── dashboard.html
│ ├── ventas.html
│ ├── productos.html
│ ├── clientes.html
│ └── reportes.html
│
├── assets/

├── docs/

│
└── README.md
